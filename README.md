# 債券部交易策略整理：利率、利差、Carry

> 從證券自營債券部的角度，整理三類交易：**利率交易（Rates / Duration）**、**利差交易（Spread）**、**Carry 交易**。

## 0. 三類交易的定位與損益拆解

一個債券部位在一段期間（Δt）內的損益，大致可以拆成：

```
P&L ≈  Carry（票息 − 融資成本）                         ← Carry 交易
     + Roll-down（曲線不變下，年限縮短的價差收益）       ← Carry 交易
     − DV01 × Δ基準利率(bp)                              ← 利率交易
     − CS01 × Δ利差(bp)                                  ← 利差交易
     + ½ × Convexity × (Δy)²                             ← 凸性
     + 其他（匯率、交易成本、基差）
```

| 交易類型 | 主要賺的是 | 主要風險 | 核心曝險指標 |
|---|---|---|---|
| 利率交易 | 基準利率（公債／IRS）的方向變動 | 利率反向走 | DV01 |
| 利差交易 | 兩個利率之間的價差變動 | 價差反向擴大／收斂 | CS01、DV01 中性後的淨曝險 |
| Carry 交易 | 時間經過的票息與滾動收益 | 利率或利差急速不利變動，一次吐回多期收益 | Carry/DV01 比、盈虧平衡 bp |

> 實務上三者常混在同一部位裡（例如買公司債 = 利率 + 利差 + carry）。好的做法是**拆開來、各自量化、只留下想要的那個曝險**，不想要的用公債、公債期貨或 IRS 對沖掉。

## 1. 利率交易 (Rates / Duration)

### 1.1 交易邏輯
押注基準利率（公債殖利率或 IRS 利率）的**方向**。
- 看利率下跌 → 做多存續期間（買債、收固定 IRS、買期貨）
- 看利率上升 → 做空存續期間（賣債／借券賣出、付固定 IRS、賣期貨）

### 1.2 驅動因子與訊號

| 類別 | 指標 | 怎麼看 |
|---|---|---|
| 貨幣政策 | 央行理監事會、重貼現率、存準率、NCD 發行量、FOMC 點陣圖 | 政策利率預期是短中端利率的錨 |
| 通膨 | CPI、核心 CPI、PPI、油價、薪資 | 通膨超預期 → 利率上升壓力 |
| 景氣 | GDP、出口訂單、PMI、景氣對策信號 | 景氣轉弱 → 長端利率下行 |
| 供給 | 公債發行計畫、標售結果（得標利率 vs. 市場、投標倍數） | 標售疲弱 → 殖利率上行 |
| 資金面 | 銀行超額準備、隔拆利率、RP 利率、壽險資金配置 | 資金寬鬆 → 利率有支撐 |
| 外部連動 | 美債 10 年、美元／台幣、外資動向 | 台債對美債的連動有落差，留意時間差 |
| 技術面 | 區間上下緣、均線、部位擁擠程度 | 用來決定進場點位與停損 |

### 1.3 工具與建倉

| 工具 | 優點 | 注意事項 |
|---|---|---|
| 指標公債（2/5/10/20/30 年） | 流動性最好、可做 RP 融資 | 新舊券流動性差異大 |
| 利率交換 IRS（固定 vs. 3M TAIBOR） | 不占資金、可做空、天期彈性 | 交換利差風險、交易對手額度 |
| 公債期貨（台灣期交所／美債期貨） | 槓桿、快速調整 DV01 | 台債期貨流動性較低，留意 CTD 與基差 |
| 借券賣出公債 | 直接做空現券 | 借券費、軋空風險 |

### 1.4 部位大小：以 DV01 計算

```
DV01 ≈ 修正存續期間 × 價格 × 面額 × 0.0001
```

範例：買入 10 年期公債面額 5 億，修正存續期間 9.2，價格 100：
`DV01 ≈ 9.2 × 5 億 × 0.0001 = 46 萬元／bp`
→ 殖利率下跌 10bp，約賺 460 萬；上升 10bp，約賠 460 萬。

**用目標 DV01 反推面額**（例如這筆交易只給 20 萬／bp 的預算）：
`面額 = 20 萬 ÷ (9.2 × 0.0001) ≈ 2.17 億`

### 1.5 停損與出場
- 以 **bp** 設停損，不以價格 % 設，例如「10 年券反向 8bp 停損」。
- 先設好**觀點失效條件**（例如「CPI 連續兩個月超過 X%」或「央行轉鷹」），條件出現就出場，不必等停損點位到。
- 報酬風險比至少 1.5–2 倍：目標 15bp、停損 8bp。

### 1.6 常見陷阱
- 部位用「面額」管理，忽略不同天期的 DV01 差異。
- 現券做多卻沒算 RP 融資成本：曲線倒掛時，持有期間的 carry 是負的。
- 遇到標售、央行會議、CPI 公布前沒有降部位，跳空風險。
- 只看台債，忽略美債與匯率的外溢效應。

## 2. 利差交易 (Spread)

押注**兩個利率之間的價差**，盡量把整體利率方向的曝險中和掉（DV01 中性）。可再細分成以下四類：

### 2.1 信用利差 (Credit Spread)
**定義：** 公司債／金融債殖利率 − 同天期公債殖利率（或 IRS）

| 觀點 | 做法 | 利率曝險處理 |
|---|---|---|
| 看利差收斂 | 買公司債 | 賣公債／賣期貨／付固定 IRS，對沖 DV01 |
| 看利差擴大 | 賣出持有的公司債，或買 CDS 保護 | 視需要保留或對沖利率曝險 |

**驅動因子：**
- 發行人基本面：獲利、槓桿、現金流、評等展望
- 供需：發行量（發行季節性）、壽險／銀行的配置需求、新發行折價 (new issue concession)
- 總體：景氣循環、股市波動、違約率
- 相對價值：同評等、同產業、同天期之間的利差排序

**衡量指標：**
```
CS01 ≈ 利差存續期間 × 部位市值 × 0.0001   （利差變動 1bp 的損益）
```

**範例：**
買 5 年期 AA 公司債 3 億，殖利率 2.10%，同天期公債 1.55% → 利差 55bp，存續期間 4.6。
- CS01 ≈ 4.6 × 3 億 × 0.0001 = 13.8 萬／bp
- 同時賣出 DV01 相等的 5 年公債（或付固定 5 年 IRS）
- 利差從 55bp 收斂到 45bp：約賺 138 萬，與公債利率的方向無關

### 2.2 曲線利差 (Curve Spread)
**定義：** 同一條曲線上不同天期的利差，例如 2s10s、5s10s、10s30s。

| 交易 | 做法（DV01 中性） | 獲利情境 |
|---|---|---|
| 陡峭化 (Steepener) | 做多短端 + 做空長端 | 降息初期短端先下（牛陡）；通膨／供給壓力使長端上升（熊陡） |
| 平坦化 (Flattener) | 做空短端 + 做多長端 | 升息循環短端先上（熊平）；衰退避險使長端下降（牛平） |
| 蝶式 (Butterfly) | 例如 2s5s10s：做多 5 年，做空 2 年與 10 年 | 中間天期相對兩翼便宜，曲度回歸 |

**DV01 中性配比：**
```
長端面額 = 短端面額 × (短端每單位 DV01 ÷ 長端每單位 DV01)
```
範例：2 年券每億 DV01 = 1.9 萬、10 年券每億 DV01 = 9.0 萬。
做多 2 年 10 億 → 做空 10 年約 `10 × 1.9 ÷ 9.0 ≈ 2.1 億`。

> 注意：DV01 中性不等於「beta 中性」。歷史上短端波動通常比長端大（或相反），可用迴歸 beta 調整權重，讓部位對平行移動更乾淨。

### 2.3 交換利差／資產交換利差 (Swap Spread / Asset Swap)
- **Swap Spread** = IRS 利率 − 同天期公債殖利率
- **Asset Swap Spread（ASW）**：買債券 + 付固定 IRS，把固定利率換成「浮動 + 利差」，鎖定純利差收益。
- **驅動因子：** 公債供給、銀行資產負債需求、TAIBOR 走勢、資金鬆緊、避險需求。
- **用途：** 公司債、金融債常用 IRS 對沖，報價以「對 IRS 的利差」來看比對公債更乾淨。

### 2.4 跨市場／相對價值利差
| 類型 | 範例 | 邏輯 |
|---|---|---|
| 新舊券 | 新發行指標券 vs. 前一期指標券 | 新券流動性溢價，標售前後的變化 |
| 現貨 vs. 期貨基差 | 公債現貨 vs. 公債期貨 | 基差到交割日會收斂 |
| 跨國 | 台債 10 年 vs. 美債 10 年 | 兩國政策分歧；需考慮匯率避險成本 |
| 同發行人不同天期 | 同一家公司 3 年 vs. 7 年 | 發行人信用曲線的斜率 |

### 2.5 利差交易的部位與風控
- 同時報兩個數字：**淨 DV01**（應接近 0）和 **CS01 或 spread DV01**（真正押注的部分）。
- 停損以利差 bp 設定，例如「利差反向 5bp 停損」。
- 留意**流動性不對稱**：公司債賣不掉、公債對沖腿很好平，壓力期間只剩利差腿。
- 留意**對沖腿的 carry**：放空公債或付固定 IRS 也有成本，要算進持有期間的淨 carry。

### 2.6 常見陷阱
- 以為 DV01 中性就沒有風險，忽略曲線形狀（對沖天期不一致）造成的殘差。
- 信用利差「便宜」可能是有原因的（評等展望負向、產業逆風）。
- 曲線交易的 carry/roll 可能是負的，時間拖越久虧越多。
- 壓力期間利差呈非線性擴大，歷史波動率會低估尾端風險。

## 3. Carry 交易

### 3.1 交易邏輯
押注「**市場不怎麼動**」：靠時間賺票息與融資成本之間的差額，加上沿曲線滾下來的資本利得。

```
Carry（每期）   = 票息收入 − 融資成本（RP 利率 × 持有天數）
Roll-down（每期）= DV01 × (目前殖利率 − Δt 後同剩餘年限在現行曲線上的殖利率)(bp)
總預期報酬      = Carry + Roll-down     （假設曲線與利差不變）
```

### 3.2 盈虧平衡分析（最重要的指標）

```
盈虧平衡 bp = (Carry + Roll-down) ÷ DV01
```
意思是：持有期間殖利率要上升超過這麼多 bp，這筆 carry 交易才會開始虧錢。

**範例：** 買 5 年期公司債 10 億，殖利率 2.10%，RP 融資 1.40%，存續期間 4.6。持有 3 個月：
- Carry ≈ 10 億 × (2.10% − 1.40%) × 3/12 = **175 萬**
- 若曲線 5 年 → 4.75 年段斜率約 2bp：Roll ≈ DV01 46 萬 × 2bp = **92 萬**
- 合計 ≈ 267 萬
- **盈虧平衡 ≈ 267 萬 ÷ 46 萬 ≈ 5.8bp**
  → 3 個月內殖利率（基準利率 + 利差）上升不超過約 5.8bp 就不會虧損。

用「盈虧平衡 bp ÷ 該期間利率的歷史波動（bp）」做成 carry-to-risk 比率，可以在不同券種、天期之間比較哪一個 carry 最划算。

### 3.3 常見的 Carry 交易類型

| 類型 | 做法 | 主要風險 |
|---|---|---|
| 公債 RP Carry | 買公債，用 RP 融資 | 曲線倒掛時為負 carry；利率上升 |
| 信用 Carry | 買公司債／金融債，用 RP 或自有資金 | 利差擴大、流動性 |
| 曲線 Roll-down | 挑曲線最陡的區段（通常 2–7 年）持有 | 曲線平坦化或倒掛 |
| 對沖後 Carry | 買公司債 + 付固定 IRS（Asset Swap） | 利差擴大、IRS 對手風險 |
| 跨國 Carry | 買外幣債券 + 匯率避險 | 避險成本變動、匯率 |
| 賣出波動率 | 賣出利率選擇權收權利金 | 尾端風險極大 |

### 3.4 部位與風控
- Carry 的本質是**賣出波動率**：平常穩定小賺，利率或利差急變時一次吐回好幾期的收益。
- 設定 **carry 部位的 DV01／CS01 上限**，並用壓力情境（例如 +50bp、利差 +50bp）檢查最大損失是否在可承受範圍。
- 留意**融資風險**：RP 利率上升、RP 對手緊縮額度、擔保品折價 (haircut) 調高。
- 會計分類會影響損益表現：
  - **FVPL**：市價變動直接進損益，carry 部位的波動完全反映在當期。
  - **FVOCI**：市價變動進其他綜合損益，票息進損益，適合中長期持有的 carry 部位。
  - **AC（攤銷後成本）**：不認列市價變動，但有出售限制。
  → 建倉前先確認部位要放在哪一類帳戶。

### 3.5 常見陷阱
- 只看「殖利率高」，沒算融資成本與 roll，實際淨 carry 可能很薄。
- 曲線倒掛時 roll-down 是負的。
- 為了放大 carry 加槓桿，壓力期遇到 RP 額度緊縮被迫賣出。
- 把 carry 收益當作「無風險」，沒有對應的停損機制。

## 4. 三類交易比較表

| 項目 | 利率交易 | 利差交易 | Carry 交易 |
|---|---|---|---|
| 押注 | 利率方向 | 兩個利率之間的相對變化 | 市場平穩、時間經過 |
| 典型持有期間 | 數天到數週 | 數週到數月 | 數月以上 |
| 獲利型態 | 方向對了賺價差 | 價差回歸或收斂 | 穩定累積 |
| 主要風險 | 方向判斷錯誤 | 價差反向、流動性不對稱 | 急速不利變動、融資 |
| 核心指標 | DV01 | 淨 DV01 + CS01 | 盈虧平衡 bp、Carry/DV01 |
| 停損方式 | 基準利率 bp | 利差 bp | 盈虧平衡被突破、壓力損失上限 |
| 主要工具 | 公債、IRS、公債期貨 | 公司債 + 公債／IRS 對沖、曲線配對 | 公債／公司債 + RP 融資 |
| 適合的市場環境 | 趨勢明確（央行轉向） | 價差偏離歷史區間 | 波動低、曲線正斜率 |

## 5. 風險指標與額度架構

| 層級 | 指標 | 說明 |
|---|---|---|
| 部門總額度 | 總 DV01、總 CS01、VaR | 公司核定的風險預算 |
| 策略額度 | 利率／利差／carry 各自的 DV01、CS01 上限 | 避免某一策略吃掉全部風險預算 |
| 單筆交易 | DV01 或 CS01 上限、停損 bp | 每筆交易事先核定 |
| 集中度 | 單一發行人、產業、天期區間 | 例如單一發行人不超過總部位 X% |
| 壓力測試 | 平行 ±50/100bp、曲線 ±25bp、利差 +50/100bp | 每週或每月檢視 |
| 流動性 | 可在 N 天內出清的比例 | 公司債、低流動券種要特別控管 |
| 停損 | 單筆、月度累計 | 觸發時降部位或暫停交易 |

**關鍵比率：**
- 利率交易：目標 bp ÷ 停損 bp ≥ 1.5
- 利差交易：利差偏離幅度 ÷ 歷史標準差（z-score），超過 ±1.5–2 再考慮進場
- Carry 交易：盈虧平衡 bp ÷ 持有期間利率波動 bp（越高越好）
