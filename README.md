## 1. 核心觀念

| 概念 | 說明 | 交易上的意義 |
|---|---|---|
| 價格與殖利率反向 | 殖利率上升 → 債價下跌 | 看利率下跌 = 做多債券 |
| 存續期間 (Modified Duration, D) | 殖利率變動 1% 時，價格約變動 D% | 衡量利率風險的主要指標 |
| DV01 / PVBP | 殖利率變動 1bp 時的價格變動金額 | 部位大小、對沖比例皆以 DV01 計算 |
| 凸性 (Convexity, C) | 價格-殖利率曲線的彎曲程度 | 正凸性在大波動時有利 |
| 殖利率曲線 | 不同到期年限殖利率的連線 | 斜率、曲度都是可交易的標的 |
| 信用利差 | 公司債殖利率 − 同天期公債殖利率 | 反映違約風險與流動性溢價 |

**價格變動近似公式：**

```
ΔP / P ≈ −D × Δy + ½ × C × (Δy)²
```

範例：存續期間 8、凸性 80 的債券，殖利率上升 1%（Δy = 0.01）：
`−8 × 0.01 + 0.5 × 80 × 0.0001 = −8% + 0.4% = −7.6%`

**債券報酬的拆解：**

```
總報酬 ≈ 票息收入 + 滾動收益(Roll-down) − D × Δ殖利率 − D_spread × Δ利差 + 匯率損益
```

幾乎所有債券策略，都是在「押注」或「收取」上式中的某一項。

## 2. 被動／配置型策略

### 2.1 持有至到期 (Buy and Hold)
- **做法：** 買入後持有到期，領取票息、到期還本。
- **適用：** 有確定資金需求時點（如退休、學費），重視現金流穩定。
- **重點：** 中途價格波動不影響最終報酬（前提是不違約），主要風險為信用風險與再投資風險。

### 2.2 階梯式 (Ladder)
- **做法：** 資金平均分配至 1、2、3…N 年到期債券；每年到期一檔，再投資到最長天期。
- **優點：** 分散再投資時點、利率風險平均化、每年有固定流動性。
- **適用：** 不想預測利率方向的長期投資人。

### 2.3 子彈型 (Bullet)
- **做法：** 集中買入到期日相近的債券（例如全部 7 年左右）。
- **適用：** 負債到期日明確；或看好曲線某一段相對便宜。

### 2.4 槓鈴型 (Barbell)
- **做法：** 同時持有短天期與長天期，中間天期留空。
- **特性：** 在相同存續期間下，凸性高於子彈型；短端提供流動性，長端提供收益。
- **適用：** 預期利率大幅波動，或預期曲線變平（Flattening）時表現較佳。

### 2.5 免疫策略 (Immunization) / 負債驅動 (LDI)
- **做法：** 讓資產存續期間 ≈ 負債存續期間，並使資產現值 ≥ 負債現值。
- **適用：** 保險、退休基金等有確定負債的機構；個人可用於「目標日期」資金規劃。
- **注意：** 需定期再平衡（Rebalance），因存續期間會隨時間與利率變化。

## 3. 利率方向（存續期間）策略

### 3.1 拉長存續期間（看多債券）
- **時機：** 預期央行降息、經濟放緩、通膨回落、避險需求上升。
- **工具：** 長天期公債、長債 ETF、買入公債期貨。
- **邏輯：** 存續期間越長，利率下跌時資本利得越大。

### 3.2 縮短存續期間（看空債券／防禦）
- **時機：** 預期升息、通膨上升、財政赤字擴大導致供給增加。
- **工具：** 短天期債、浮動利率債 (FRN)、放空公債期貨、反向債券 ETF。

### 3.3 存續期間戰術調整範例

| 觀點 | 基準存續期間 | 調整後 |
|---|---|---|
| 強烈看多 | 6 年 | 8–9 年 |
| 中性 | 6 年 | 6 年 |
| 看空 | 6 年 | 3–4 年 |

> 建議以 DV01 而非「本金金額」來衡量調整幅度。

## 4. 殖利率曲線策略

先定義利差：`2s10s = 10 年殖利率 − 2 年殖利率`

### 4.1 陡峭化交易 (Steepener)
- **做法：** 做多短端 + 做空長端（**DV01 中性**）。
- **獲利情境：**
  - *Bull steepening*：降息初期，短端利率下跌較快（最常見）。
  - *Bear steepening*：通膨或財政擔憂，長端利率上升較快。

### 4.2 平坦化交易 (Flattener)
- **做法：** 做空短端 + 做多長端（DV01 中性）。
- **獲利情境：**
  - *Bear flattening*：升息循環中，短端利率上升較快。
  - *Bull flattening*：避險或經濟衰退預期，長端利率下跌較快。

### 4.3 DV01 中性配比

```
長端名目金額 = 短端名目金額 × (短端 DV01 / 長端 DV01)
```

範例：2 年債 DV01 每百萬 = 190 美元、10 年債 DV01 每百萬 = 880 美元。
做多 2 年 1,000 萬 → 做空 10 年約 `1000 × 190 / 880 ≈ 216 萬`。

### 4.4 蝶式交易 (Butterfly)
- **做法：** 例如 2s5s10s：做多（或做空）中間 5 年，同時反向操作兩翼 2 年與 10 年。
- **押注：** 曲線「曲度」的變化，對整體平行移動與斜率變化中性。
- **常見配比：** 50/50 DV01 權重，或以迴歸 (regression) 權重消除斜率曝險。

## 5. Carry 與 Roll-down

### 5.1 概念
- **Carry：** 票息收入 − 融資成本（例如以 Repo 利率融資）。
- **Roll-down：** 在正斜率曲線下，隨著時間經過，債券剩餘年限縮短，殖利率沿曲線「滾下」而產生的資本利得。

```
預期報酬（利率不變） ≈ Carry + D × (目前殖利率 − 一段時間後同剩餘年限的殖利率)
```

### 5.2 策略
- 挑選曲線**最陡**的區段持有（通常是 2–7 年區間），在利率不變下賺取最多 carry + roll。
- **盈虧平衡分析：** `Breakeven 殖利率上升幅度 ≈ (Carry + Roll) / D`，用以判斷「利率要上升多少才會虧損」。

### 5.3 風險
- 曲線倒掛時 carry / roll 可能為負。
- 本質上是「賣出波動率」的策略，利率急升時可能一次回吐多期收益。

## 6. 信用利差策略

### 6.1 信用等級輪動
| 景氣階段 | 偏好 |
|---|---|
| 復甦初期 | 高收益債 (HY)、信用利差最寬時進場 |
| 擴張中期 | 投資等級債 (IG)、BBB 收取利差 |
| 景氣末期 | 提升信用品質、降低 HY |
| 衰退 | 公債、AAA，避開信用風險 |

### 6.2 利差交易方式
- **做多信用：** 買入公司債，同時放空公債期貨或做利率交換 (IRS) 對沖利率風險 → 純賺利差收斂。
- **做空信用：** 買入 CDS 保護、放空高收益債 ETF。
- **基差交易：** 公司債利差 vs. CDS 利差（CDS-Bond Basis）的偏離。

### 6.3 選債重點
- 槓桿比率、利息保障倍數、自由現金流。
- 評等展望（降評至非投資等級的「墮落天使」風險／機會）。
- 發行條款：可贖回 (Callable)、次順位、永續債的額外風險。
- 流動性：發行量、買賣價差。

### 6.4 墮落天使 (Fallen Angels) 策略
- 被從 IG 降評為 HY 的債券，常因機構被迫賣出而超跌，歷史上有反彈溢酬。

## 7. 相對價值（Relative Value）策略

> 多為機構使用，需要槓桿、融資與精確對沖；個人投資人了解原理即可。

| 策略 | 做法 | 獲利來源 |
|---|---|---|
| 新舊券價差 (On-the-run / Off-the-run) | 做多較便宜的舊券、做空新券 | 流動性溢價收斂 |
| 現貨-期貨基差 (Cash-Futures Basis) | 買現貨公債 + 賣期貨（或反向） | 基差收斂至交割 |
| 交換利差 (Swap Spread) | 公債 vs. 同天期利率交換 | 利差偏離歷史區間後回歸 |
| 曲線擬合偏離 | 以 Nelson-Siegel 等模型找出偏離曲線的個券 | 相對貴／便宜的修正 |
| 跨市場利差 | 例如美債 vs. 德債 10 年 | 貨幣政策分歧 |

**注意：** 這類交易利潤薄、槓桿高，極端行情（如 2020 年 3 月）可能因流動性枯竭而巨額虧損。

## 8. 通膨連結債策略

- **損益平衡通膨率 (Breakeven Inflation)：**
  `BEI = 名目公債殖利率 − 同天期 TIPS 實質殖利率`
- **策略：**
  - 預期實際通膨 > BEI → 做多 TIPS（或做多 breakeven：買 TIPS、賣名目債）。
  - 預期實際通膨 < BEI → 持有名目公債。
- **適用時機：** 通膨上行初期、能源／商品價格大漲、央行被認為落後於曲線。
- **風險：** 實質利率大幅上升時，TIPS 價格仍會下跌。

## 9. 跨國債券與匯率避險

### 9.1 避險成本
```
避險後殖利率 ≈ 外國債券殖利率 − (外幣短率 − 本幣短率)
```
- 以台灣投資人買美債為例：美元短率明顯高於台幣時，避險成本高，避險後收益可能大幅縮水。

### 9.2 選擇
| 方式 | 優點 | 缺點 |
|---|---|---|
| 不避險 | 保留完整殖利率；美元在避險時常走強，有分散效果 | 承擔匯率波動，可能吃掉債券報酬 |
| 完全避險 | 報酬貼近債券本身 | 避險成本高時收益偏低 |
| 部分／動態避險 | 依匯率觀點調整 | 需判斷匯率走勢 |

### 9.3 台灣投資人常見工具
- 美國公債 ETF（不同天期：短、中、20 年以上）。
- 投資等級公司債 ETF。
- 境外基金、複委託直接買美債。
- 注意：配息課稅、二代健保補充保費、ETF 折溢價及內扣費用。

| 階段 | 利率／通膨環境 | 存續期間 | 曲線 | 信用 |
|---|---|---|---|---|
| 復甦 | 利率低、通膨低 | 中性偏短 | 陡峭化 | 加碼 HY |
| 擴張 | 利率上升、通膨升溫 | 縮短 | 熊市平坦化 | IG 為主，減少 HY |

| 工具 | 用途 | 適合對象 |

## 12. 風險管理

1. **以 DV01 管理部位：** 設定整體 DV01 上限，每筆交易的 DV01 曝險明確。
2. **情境分析：** 平行移動 ±100bp、曲線陡峭／平坦 ±50bp、信用利差擴大 +200bp（衰退情境）。
3. **停損規則：** 以殖利率點數（bp）設定，例如「10 年殖利率反向 25bp 即停損」，而非僅看價格百分比。
4. **流動性風險：** 高收益債、新興市場債、小量發行債在壓力期可能難以出場。
5. **再投資風險與贖回風險：** 可贖回債在利率下跌時可能被提前贖回。
6. **槓桿風險：** Carry 與相對價值交易常使用槓桿，需注意融資成本與追繳保證金。
7. **集中度：** 單一發行人、單一產業、單一國家的曝險上限。
8. **交易紀錄：** 每筆交易記錄進場理由、目標、停損、預期持有期間，事後檢討。
